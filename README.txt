MY TITHE JOURNEY — ANDROID-READY PACKAGE
Worship Flames Ecclesia

This package contains the existing My Tithe Journey web app plus Android/PWA packaging files.

Included:
- index.html — app interface
- manifest.webmanifest — installable-app metadata
- sw.js — offline/service-worker foundation
- icon.svg — app icon

Important:
Reliable weekly notifications while the app is completely closed require a push-notification service or native Android scheduling. This package provides the PWA foundation; the final APK/Play Store build is the next packaging step after the app is hosted at an HTTPS address.
